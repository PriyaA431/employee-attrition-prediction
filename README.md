
# Employee Attrition Prediction

A Machine Learning project that predicts whether an employee is likely to leave an organization using HR analytics data.

## 🎯 Objective

The goal of this project is to analyze employee data, identify factors contributing to attrition, and build a predictive machine learning model to help organizations improve employee retention.

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib
